About the Project

A machine learning system that learns to think like a fraud investigator.

Built with Python, scikit-learn, and Flask, this project applies classical ML techniques to the PaySim financial dataset — 6.3 million synthetic mobile money transactions.

The model detects fraudulent TRANSFER and CASH_OUT operations using six engineered features: transaction type, amount, and four balance signals.

Process

How it works

01

Data Input

Enter transaction type, amount, and four balance fields (origin old/new, destination old/new). No personal data required.

02

Feature Engineering

Transaction type is label-encoded. Balance deltas are computed implicitly. The vector is passed to the trained model.

03

ML Inference

A balanced Random Forest classifier — trained with class-weight correction — predicts fraud vs. legitimate in milliseconds.

04

Result Displayed

A clear verdict: Safe or Fraud Detected — with visual feedback and next actions.

Capabilities

What the model can do

🧠

Random Forest Classifier

An ensemble of decision trees jointly vote on whether a transaction is fraudulent. Robust to outliers and noise, with class-weight=balanced for imbalanced fraud data.

⚡

Real-Time Prediction

Sub-100ms inference via Flask REST API.

🎯

5 Transaction Types

TRANSFER, CASH_OUT, CASH_IN, PAYMENT, DEBIT — all handled.

⚖️

Imbalance Handling

Only ~0.13% of records are fraud. Undersampling + class weighting ensures the model learns fraud patterns, not just non-fraud.

📊

Model Comparison

Logistic Regression, Decision Tree, and Random Forest were all evaluated; best F1 wins.
